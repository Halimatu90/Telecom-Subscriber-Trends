# Telecom-Subscriber-Trends
The Telecom Subscriber Trends is  an end-to-end data analytics project evaluating mobile network performance, user behaviour, and service quality in Lokogoma community. It transforms raw telecom metrics into actionable business intelligence to guide network optimization and customer retention across major operators (MNT, Airtel, Glo, 9mobile).Project Topic: Telecom Subscriber Trends
Case Study: Lokogoma Community


**Executive Summary**

This report analyzes the Telecom Subscriber Trends Dashboard, providing an overview of key performance indicators (KPIs), network data usage, subscriber demographics, usage purposes, and device distributions based on the visual data presented.

**Detailed Metric Analysis**

1. Network Performance & Data Usage


•	Data Usage by Network: MTN commands the vast majority of total data usage (Sum of Monthly Data GB exceeding 2.5K GB), significantly outperforming 9mobile.

•	Data Usage vs. Monthly Expenditure: MTN shows high concentration in both monthly expenditure (around 170K–180K) and data volume (~300 GB in this specific segment view).

2. Subscriber Demographics & Behaviour


•	Internet Purpose Breakdown: Equal distribution (2 subscribers / 4.65% each visible segment) across major usage drivers: social media, Work, Entertainment, Business, and Education.

•	Device Distribution:


o	iPhone: 37 subscribers (86.05%)

o	Feature Phone: 6 subscribers (13.95%)

•	Subscriber ID by Age: Age distribution ranges across various demographics, peaking near the 50-year-old mark.

•	Payment Methods: Individual subscribers (e.g., SUB00076 to SUB01167) show a uniform 1.0 count per payment method category, indicating single-method preference per user.

Dashboard Filters Active

•	Gender: Filter available for Female / Male selection.

•	Network Quality: Options include Excellent, Fair, and Good (Currently filtered to Excellent).

•	Device Type: Currently filtered for Feature Phone and iPhone.

**Data Anomalies & Recommendations**

•	Satisfaction Metric: The "Avg. Satisfaction" metric displays 367%. It is recommended to update the underlying measure from SUM to AVERAGE or cap the percentage scale at 100% to ensure accurate reporting.

•	Subscriber ID by Age Chart: The bar chart for age displays dense count lines; switching to age brackets (e.g., 18–25, 26–35) would improve readability.
